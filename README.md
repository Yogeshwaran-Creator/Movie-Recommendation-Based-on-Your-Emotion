# 🎬 Movie Recommendation Based on Your Emotion

A Python-based Streamlit application that recommends movies based on the user's current emotion.

## ✨ Features

- 🎭 Emotion-based movie recommendations
- 🎬 Interactive user interface
- ⚡ Quick and simple recommendations
- 🌐 Deployed using Streamlit Community Cloud

## 🛠️ Technologies Used

- Python
- Streamlit
- Git & GitHub
- Streamlit Community Cloud

## 🚀 Run Locally

```bash
pip install streamlit
streamlit run mini.py
